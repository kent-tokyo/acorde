# Standard-bass screen for harmony and groove proposals

`screen_harmony_groove_standard_bass(source, resolved, profile)` is an opt-in Rust API. The full and viewer WASM builds expose the same function with three JSON strings. Save the original `Score`, a candidate's `resolved` contract, and the instrument's `StandardBassProfile`; the screen replays the candidate from that source before judging it. A modified source or invalid button inventory returns a typed error. The unrestricted `suggest_harmony_groove_arrangements` and free-bass playback paths remain available.

The left hand consists of the generated accompaniment part and, when the request names one, its source bass staff within the selected measures. The screen uses the resulting score's playback events, including repeat visits, and checks each sounding state after an attack or release. It compares the complete MIDI pitch **multiset** with one bass button, one chord button, or a reachable bass-plus-chord pair. A match uses the supplied buttons' actual MIDI pitches and preserves repeated unisons; matching a chord symbol or pitch classes alone is insufficient. The bass-button ID may identify a counterbass. The profile supplies that meaning, because Acorde does not infer an instrument layout from the ID.

The report gives `playable_with_supplied_profile`, `button_states`, and location-aware `diagnostics`. Each state records the time, measure, source note addresses, exact sounding pitches, selected bass/chord button IDs, and their pitches. A false verdict means this **exact** generated score has no one-bass/one-chord-button realization in the supplied profile. It does not rule out another standard-bass combination, or a new edition with fewer inner voices or a different voicing. No melody notes are deleted or changed by the screen. A host can show an unrestricted candidate as free-bass when its exact score fails, or request a simpler edition and screen that separately.

This is an exact pitch and simultaneous reach check, not a fingering certificate. It does not certify ergonomics, bellows, hand transitions, or a different instrument's buttons. A successful result still requires performer review. Microtonal pitch and pitch bends in the selected left hand are rejected rather than rounded to MIDI notes. The bounded screen allows at most 4,096 left-hand playback events; an exceeded bound returns an error, not an unplayable verdict.
